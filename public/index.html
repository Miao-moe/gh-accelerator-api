GitHub Accelerator API

GitHub 加速镜像站聚合 API - 提供全球 GitHub 加速节点查询

API 端点

GET /api/mirrors

获取所有镜像节点列表

GET /api/mirrors/:type

按类型筛选镜像。类型: file-download | direct-access | clone | academic

GET /api/random

随机获取一个可用镜像节点

GET /api/search?q=关键词

搜索镜像节点

GET /api/stats

获取镜像统计信息

返回示例

{
  "success": true,
  "total": 100,
  "lastUpdated": "2026-08-27T00:00:00Z",
  "mirrors": [
    {
      "name": "gh-proxy.com",
      "url": "https://gh-proxy.com/",
      "type": "file-download",
      "status": "active",
      "features": ["Releases", "Raw", "Archive", "Git Clone"]
    }
  ]
}

自动更新

运行 npm run update 可从源站自动抓取最新镜像节点并合并到数据库。
